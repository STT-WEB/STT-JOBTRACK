### หน้าย่อยใหม่ "2 · ค่าแรง เทียบ OT"
- KPI 5 ช่อง: ค่าแรงปกติสะสม · ค่า OT สะสม · ค่าแรงรวม · ชั่วโมง OT รวม · **OT ต่อชั่วโมงปกติ (%)**
- กราฟแท่ง **ค่าแรงปกติ vs ค่า OT รายเดือน** — ชี้เมาส์เห็นยอดเต็มทั้งสองก้อน + สัดส่วน OT + ชั่วโมง OT
- ตารางรายเดือน: ค่าแรงปกติ / ค่า OT / รวม / สัดส่วน OT / ชม.ปกติ / ชม. OT1.5 / ชม. OT3 / **ค่า OT เทียบเดือนก่อน (▲▼%)**
- กราฟ **สัดส่วน OT ต่อเดือน (%)** แยกออกมาอีกกราฟ (ไม่เอาไปยัดแกนที่สอง เพราะคนละหน่วย อ่านผิดง่าย)
- **เจาะดูเดือนเดียว → แยกตามแผนกใหญ่**: เลือกเดือนได้ เห็นค่าแรงปกติ/ค่า OT/สัดส่วน OT/ชั่วโมง/จำนวนคน รายแผนก
  · ช่องสัดส่วน OT **ระบายเหลืองเมื่อเกิน 12% แดงเมื่อเกิน 18%** (เกณฑ์นี้ปรับได้ บอกมาได้เลย)
- ด่านตรวจ: ค่าแรงปกติ + ค่า OT = ยอดรวมเดือนเป๊ะ

### แท็บ Job Cost (ค่าแรง) — ตัดวัตถุดิบออกแล้ว
คอลัมน์: รหัสจ๊อบ · ชื่องาน · ประเภท · **ชม.ตามงบ · ชม.จริง · ต่าง (ชม.)** · อัตรา/ชม. · **งบค่าแรง · ค่าแรงจริง · ผลต่าง (บาท) · ต่าง % · สถานะ**
\+ กราฟผลต่างจากงบเรียงจากเกินงบมากสุด (แดง = เกินงบ / เขียว = ต่ำกว่างบ)
\+ ด่านตรวจ: ชั่วโมงจริง × อัตรา/ชม. = ค่าแรงจริงทุกบรรทัด และ งบ + ผลต่าง = จริง
> วัตถุดิบ / Budget Sale / กำไรขั้นต้น จะเพิ่มเป็น**ชั้นถัดไป** เมื่อเบียร์บอกแหล่งข้อมูล

### KEMREX = "แผนก" ไม่ใช่ "บริษัท" (แก้ตามที่เบียร์บอก)

คน KEMREX ที่มาทำงานที่ STT อยู่ใน **DATA BASE 2569 เดียวกันกับทุกคน** ต่างกันแค่ **รหัสแผนก** ระบบจึงทำแบบนี้:

| จุด | ทำอะไร |
|---|---|
| หน้าเลือกบริษัท | เหลือ **STT / S1** เท่านั้น (ตัด KEMREX ออกจากการเป็นบริษัท) |
| แผนกใหญ่ของ STT | จาก 11 เป็น **12 แผนก** — เพิ่ม **`10 · KEMREX`** (จัดเป็น Direct) |
| ยอดรวม STT | **รวมแผนก KEMREX อยู่แล้วโดยอัตโนมัติ** — ไม่ต้องไปรวมทีหลัง |
| ปุ่มสลับที่หัวโมดูล | **"นับรวม / ไม่นับ"** แผนก KEMREX — กดแล้วทุกหน้าในโมดูลค่าแรงเปลี่ยนตามทันที (KPI, กราฟ, ตาราง, ตัวกรอง, ด่านตรวจ) พร้อมแถบเตือนสีเหลืองเมื่อกำลังดูแบบไม่นับ |
| หน้าย่อยที่ 3 (เดิม "CEO รวม STT+KEMREX") | เปลี่ยนเป็น **"มุมมองผู้บริหาร (STT + KEMREX)"** — แยกให้เห็นชัดว่าค่าแรงส่วนไหนเป็นคน STT เอง ส่วนไหนเป็นคน KEMREX พร้อมสัดส่วนรายเดือน (หน้านี้แสดงยอดรวมทั้งหมดเสมอ ไม่ขึ้นกับปุ่มด้านบน) |
| S1 | ไม่มีแผนก KEMREX → ปุ่มสลับและหน้าย่อยที่ 3 ซ่อนอัตโนมัติ |

> ⚠️ **ต้องยืนยัน 1 อย่าง:** ผมใส่รหัสแผนก KEMREX เป็น **10** (เพราะรหัสที่เบียร์ให้มามี 1–9, 11, 12 — เลข 10 ว่างอยู่)
> ถ้าของจริงเป็นเลขอื่นบอกได้ครับ แก้บรรทัดเดียว

**การตัดสินใจเรื่องสีที่ขอให้เบียร์ดู:** แผนกมี 12 แผนก แต่ตาคนแยกสีได้ดีสุดประมาณ 7–8 สี
→ กราฟจึงโชว์ **7 แผนกที่ค่าแรงสูงสุดแยกสี** ที่เหลือรวมเป็น **"อื่นๆ" (สีเทากลาง)**
→ **ยอดครบทุกแผนกดูได้ที่ตารางด้านล่างกราฟ กางแผนกย่อยได้**
→ สีผูกกับ *ตัวแผนก* ไม่ใช่อันดับ — เปลี่ยนตัวกรองแล้วสีไม่สลับ

## 2. หน้าที่ทำมาให้ดูแล้ว (คลิกได้จริงทุกหน้า)

### กลุ่มเข้าระบบ
1. **Login** — โลโก้ STT + S1, ชื่อ STT NOVA-HR ใหญ่, รูปพนักงานจับมือ (พื้นหลังโปร่ง), input มืด, ปุ่ม LINE
2. **ลงทะเบียนพนักงาน** — ผูก LINE กับรหัสพนักงาน → HR อนุมัติ
3. **เลือกบริษัท** — STT / S1 (การ์ดละแบรนด์ + สีประจำ)
4. **บทบาท + PIN** — ผู้บริหาร / HR / หัวหน้าแผนก / พนักงาน

### Hub (หน้าหลัก)
5. **หน้ารวม 6 กล่อง** — ค่าแรง·ต้นทุน (พร้อมใช้) · สรรหา · กิจกรรม · ทักษะ · พนักงาน (โครงหน้า) · My Account
   + กล่องอธิบาย "ระบบทำงานยังไง" และ "การ Deploy" ให้เอาไปพรีเซนต์ได้เลย

### ค่าแรง · ต้นทุนงาน (8 แท็บ)
6. **สรุปค่าแรง** — 5 หน้าย่อย (นี่คือหัวใจ ครบ 5 ข้อที่เบียร์เคาะ)
   - ① กราฟค่าแรงรายเดือนแยกแผนกใหญ่
   - ② ชี้เมาส์ที่แท่ง → ขึ้น **ยอดเต็มทุกแผนก + ยอดรวม + %เทียบเดือนก่อน** (ไม่ย่อ ฿K)
   - ③ แถบสีต่อแผนกใหญ่ + ตารางครบทุกแผนก (STT = 12 รวม KEMREX) กางดูแผนกย่อยได้
   - ④ Direct / Indirect (ยอด + % ทั้งสะสมและรายเดือน)
   - ⑤ รายละเอียดรายพนักงาน ตามเดือน (คลิกแถว → เด้งไปหน้า My Account ของคนนั้น)
   - + **ค่าแรง เทียบ OT** (หน้าย่อยใหม่ — ดูรายละเอียดด้านบน)
   - + **เทียบรายปี 2567–2569** (ดึงจากแท็บ HR&ACC) และ **มุมมองผู้บริหาร — แยกคน STT / คน KEMREX**
   - + **ด่านตรวจ** ทุกหน้า: บอกให้เห็นกับตาว่าผลรวม 3 ทางตรงกัน
7. **Time Bplus** — โชว์สถานะจริงว่าไฟล์ยังเป็น Excel ต้องแปลงก่อน + ปุ่มแปลง/นำเข้า
8. **Time JOBTRACK** — ชั่วโมงรายวัน + ตัวกรอง 4 ชั้น + **แถวแดง "ลืม Check Out"** (งานค้างที่ยังไม่ได้ทำ)
9. **Reconcile** — เดือนที่ไม่มีไฟล์ Bplus บอกตรง ๆ ว่าเทียบไม่ได้ · เดือนที่เทียบได้ชี้เฉพาะบรรทัดที่ต่าง
10. **Data Payroll** — Gross / ประกันสังคม / Net กรองตามเดือน+แผนก
11. **Cal Jobcost** — **โชว์สูตรทุกบรรทัด** ให้ตรวจย้อนได้เอง
12. **Dashboard** — ไทม์ไลน์วันเริ่มงาน→วันส่งมอบ (เขียว=ตรงเวลา / แดง=เลยกำหนด / น้ำเงิน=อยู่ในช่วง) · กรองวันที่ · กรองเกรด Performance · กราฟสัดส่วนค่าแรงตามประเภทงาน · หน้า Verify รายเดือน · ตารางเจาะทุกจ๊อบ
13. **Job Cost (ค่าแรง)** — งบค่าแรง vs ค่าแรงจริง รายจ๊อบ (ยังไม่รวมวัตถุดิบ)

### หน้าอื่น
14. **My Account** — พนักงานเห็นชั่วโมง/ค่าแรงของตัวเอง (ตัวเลขชุดเดียวกับที่ HR เห็น)
15. **โครงหน้า 4 โมดูล** — สรรหา / กิจกรรม / ทักษะ / พนักงาน — มี Flow งาน + คำถามที่ต้องเคาะ ในแต่ละกล่อง

## 3. เรื่องที่ต้องให้เบียร์เคาะ (ตอบแล้วเดินต่อได้ทันที)

### 3.0 ยืนยันเรื่อง KEMREX
- [ ] รหัสแผนกของ KEMREX ในไฟล์จริงคือเลขอะไร (ผมสมมติเป็น **10**)
- [ ] คน KEMREX นับเป็น **Direct** (ต้นทุนผลิต) ใช่ไหม — ตอนนี้ตั้งไว้เป็น Direct
- [ ] ค่าเริ่มต้นเวลาเปิดหน้า ควรเป็น **"นับรวม"** ใช่ไหม (ตอนนี้ตั้งไว้เป็นนับรวม)

### 3.1 ด่วน — บล็อกไม่ให้ทำ Job Cost ต่อ
1. **Estimate (งบค่าแรง หรือ ชั่วโมงคนตามงบ)** อยู่ไฟล์ไหน แท็บอะไร คอลัมน์ชื่ออะไร · ผูกกับรหัสจ๊อบยังไง
   → ตอบข้อนี้ข้อเดียวก็ต่อข้อมูลจริงในแท็บ Job Cost ได้เลย
2. *(ไว้ทีหลัง เมื่อพร้อมเพิ่มวัตถุดิบ)* **ค่าวัตถุดิบจริง** ดึงจากจัดซื้อ/สโตร์ หรือคีย์มือ · **Budget Sale** อยู่ไฟล์ไหน
3. เกณฑ์เตือนสัดส่วน OT ใช้ **12% / 18%** ตามที่ผมตั้งไว้ หรือจะเปลี่ยนเป็นเท่าไหร่

### 3.2 ยืนยันดีไซน์ (ตอบสั้น ๆ ว่า "ผ่าน" หรือ "แก้ตรงไหน") — ทีละกล่อง
- [ ] กล่อง A · หน้า Login / เลือกบริษัท / PIN
- [ ] กล่อง B · หน้า Hub + การแบ่ง 6 โมดูล
- [ ] กล่อง C · สรุปค่าแรง 5 ข้อ + หน้า "ค่าแรง เทียบ OT" (หัวใจ)
- [ ] กล่อง D · แท็บ Time Bplus / JOBTRACK / Reconcile / Data Payroll / Cal Jobcost
- [ ] กล่อง E · Dashboard
- [ ] กล่อง F · Job Cost (ค่าแรง)
- [ ] กล่อง G · My Account
- [ ] กล่อง H · โครงหน้า 4 โมดูล (สรรหา/กิจกรรม/ทักษะ/พนักงาน)

### 3.3 คำถามในแต่ละโมดูลที่ยังเป็นโครง
อยู่ในหน้าโมดูลนั้น ๆ ในกล่อง **"ต้องถามเบียร์ก่อนทำจริง"** — เปิดดูแล้วตอบในไฟล์นี้ได้เลย

| **ตัวตรวจกราฟล้นกรอบ** — ไล่ทุกกราฟ ทุกแท็บ ทุกเดือน ทั้งเปิด/ปิด KEMREX ทั้ง STT และ S1 | ✅ ไม่มีอะไรวาดออกนอกกรอบ |
