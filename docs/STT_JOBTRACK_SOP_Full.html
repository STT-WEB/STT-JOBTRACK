PART 2 — Admin (ผู้ดูแลระบบ)

เพิ่ม Job · ออก QR Code · ลงทะเบียนพนักงาน · จัดการ Employee_List

🗂️
Admin
จัดการ Job_List และ Employee_List ผ่าน Google Sheet ออก QR Code พิมพ์ติดหน้างาน
2.1 งานประจำวันที่ Admin ต้องทำ
ช่วงเวลาสิ่งที่ต้องตรวจวิธีตรวจ
เช้าพนักงาน Check In ค้างข้ามคืนไหมJob_Log → Filter สถานะ "Check In" + วันเมื่อวาน
มีงานใหม่เพิ่ม Job ใหม่ใน Job_Listกรอก Column A B C → QR Link ขึ้นอัตโนมัติ
มีพนักงานใหม่Import พนักงานและแจก QR Registerดูขั้นตอน 2.3
2.2 การเพิ่ม Job ใหม่และออก QR Code
1
เปิด Google Sheet JOBTRACK_Database → Tab Job_List
2
เลื่อนลงแถวว่างสุดท้าย → กรอกข้อมูล 3 ช่อง
Column A = ประเภทงาน: JM / JT / JMS / JP / Other Job Column B = Job Code: เช่น JM-69/0100 Column C = ชื่อลูกค้า: บริษัท xxxxxx จำกัด
3
กด Enter → Column E (QR Link) จะขึ้นอัตโนมัติทันที ✅
💡 ถ้า QR Link ไม่ขึ้น แจ้งเจ้าของระบบให้ Run testInstallTrigger
4
ดูรูป QR Code ใน Column H (สูตร =IMAGE(...))
💡 ถ้ายังไม่มี ใส่สูตรนี้ใน Column H: =IMAGE("https://api.qrserver.com/v1/create-qr-code/?size=300x300&data="&E2)
5
พิมพ์ QR Code → ตัดแล้วติดที่แท็งค์/หน้างาน
❌ อย่าพิมพ์ QR จาก Column E (URL ยาวเกิน) ให้พิมพ์จาก Column H (รูป QR)
⚠️ Job Code ต้องไม่ซ้ำกัน | QR เก่าที่ติดอยู่ยังใช้ได้แต่จะโหลดชื่องานช้ากว่าเล็กน้อย
2.3 การลงทะเบียนพนักงานใหม่
1
ตรวจสอบว่าพนักงานใหม่มีชื่อใน Tab DATA EMPLOYEE แล้ว
💡 ถ้ายังไม่มี → เพิ่มข้อมูลใน DATA EMPLOYEE ก่อน
2
Apps Script → เลือก testImportEmployee → ▶ Run
💡 LINE ID เดิมของพนักงานคนอื่นจะไม่หาย
3
พิมพ์ QR Register แจกพนักงานใหม่
URL: https://stt-web.github.io/STT-JOBTRACK/register.html → QR Register ใบเดียวใช้ได้กับพนักงานทุกคน
4
นั่งเฝ้า → พนักงานสแกน QR ด้วยกล้องมือถือ (ไม่ใช่ LINE) → Login LINE → กรอกรหัสพนักงาน
5
ตรวจ Tab Employee_List → คอลัมน์ D (LINE ID) ควรมีข้อมูลแล้ว
2.4 การปิด Job ที่เสร็จแล้ว
1
ตรวจ Job_Log → ไม่มีพนักงาน Check In ค้างใน Job นั้น
2
Tab Job_List → คอลัมน์ D → เปลี่ยนจาก Active เป็น Done
3
ถอด QR Code ออกจากหน้างาน

PART 3 — พนักงาน (Employee)

ลงทะเบียนครั้งแรก · Check In ก่อนเริ่มงาน · Check Out + ถ่ายรูปทุกครั้ง

👷
พนักงาน
สแกน QR ที่หน้างาน → Check In/Out → ถ่ายรูป Evidence ทุกครั้ง
🚫 ห้ามเปิด App จาก LINE Browser เด็ดขาด! ต้องใช้ Chrome หรือ Safari เท่านั้น
3.1 การลงทะเบียนครั้งแรก (ทำครั้งเดียวตลอดไป)
1
รับ QR Register จาก HR หรือ Admin
2
เปิดกล้องมือถือ (ห้ามเปิดจาก LINE) → สแกน QR
❌ ถ้าเปิดจาก LINE → กด ⋮ 3 จุด → เปิดใน Chrome
3
กด "เข้าสู่ระบบด้วย LINE" → เลือก Account ของตัวเอง
4
กรอกรหัสพนักงาน (ตัวเลข) ด้วย Numpad บนหน้าจอ
💡 รหัสดูจากสลิปเงินเดือน หรือถาม HR/Admin
5
กด ยืนยัน → ตรวจสอบชื่อและแผนกที่ขึ้นมา → หน้า "ลงทะเบียนสำเร็จ" ✅
6
เพิ่ม Shortcut บน Home Screen
Chrome Android: ⋮ → เพิ่มในหน้าจอหลัก Safari iOS: แชร์ → เพิ่มในหน้าจอโฮม
💡 ครั้งต่อไปกดจาก Icon ที่ Home Screen ได้เลย
3.2 การ Check In เข้างาน
1
เดินไปที่แท็งค์/หน้างาน → เปิดกล้องมือถือ → สแกน QR Code ของงานนั้น
2
ตรวจสอบชื่อตัวเองและ Job ที่แสดงบนหน้าจอ
❌ ถ้าชื่อหรือ Job ผิด → ปิดแล้วสแกน QR ใหม่
3
กด ▶ เข้างาน (ปุ่มสีเขียว)
4
เลือก Process ที่กำลังทำ → กด บันทึก → รอหน้า "เข้างานสำเร็จ" ✅
5
กด "⚙️ ขอแก้ไข Process" ถ้าเลือกผิด (แก้ได้แค่ 1 ครั้งเท่านั้น)
💡 หลังแก้แล้ว ไม่มีปุ่มกลับหน้าหลัก — ต้องสแกน QR ใหม่เมื่อพร้อม Check Out
🚫 ถ้าระบบแจ้ง "มีงานค้างอยู่" → ต้องไป Check Out งานเดิมก่อนเท่านั้น
3.3 การ Check Out ออกงาน
1
สแกน QR ของงานนั้น → กด ■ ออกงาน (ปุ่มสีแดง)
2
Section ถ่ายรูปปรากฏขึ้น → กด ถ่ายรูป
💡 บังคับถ่ายอย่างน้อย 1 รูป สูงสุด 3 รูป
3
ถ่ายรูปงานให้เห็นชัดเจน → กด ตกลง → กด บันทึก
❌ ห้ามใช้รูปจาก Gallery ระบบจะปฏิเสธอัตโนมัติ ต้องถ่ายสดเท่านั้น
4
หน้า "ออกงานสำเร็จ" ขึ้นพร้อมชั่วโมงรวม → กด "✅ เสร็จสิ้น — ปิดหน้านี้"
3.4 กรณีพิเศษ
กรณีวิธีแก้ไข
ลืม Check Outแจ้ง Admin ทันที ให้ Admin แก้ใน Job_Log
Check In ผิด Jobแจ้ง Admin ทันที อย่า Check Out เอง
เปลี่ยนมือถือ / มือถือหายแจ้ง Admin → ลบ LINE ID เดิม → ลงทะเบียนใหม่ผ่าน QR Register
กล้องไม่ทำงานเปิดจาก LINE Browser → กด ⋮ → เปิดใน Chrome
เน็ตไม่มีรอจนมีเน็ต แล้ว Check In/Out ตามเวลาจริง
3.5 Do & Don't
✅ ต้องทำ
✅ Check In ทุกครั้งก่อนเริ่มงาน
✅ Check Out ทุกครั้งที่เสร็จงาน
✅ ถ่ายรูปงานให้ชัดเจนทุกครั้ง
✅ เปิด App จาก Chrome เท่านั้น
✅ แจ้ง Admin ทันทีถ้ามีปัญหา
❌ ห้ามทำ
❌ เปิด App จาก LINE Browser
❌ ใช้รูปจาก Gallery
❌ Check In แทนกัน
❌ Check In ค้างข้ามวันโดยไม่แจ้ง
❌ ถ่ายรูปอะไรก็ได้ที่ไม่ใช่งาน
