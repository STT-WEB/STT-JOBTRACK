# สถานะงานตามที่เบียร์สั่ง — ตรวจตรงไปตรงมา

อัปเดต: 19 ส.ค. 2026 · โดย Candy

**สัญลักษณ์สถานะ**
- ✅ = เขียนโค้ด + ตรวจในเครื่องแล้ว **แต่เบียร์ยังไม่ได้ยืนยันว่าใช้ได้จริงบนเว็บ**
- 🟡 = ทำบางส่วน / เป็น mockup ยังไม่ต่อข้อมูลจริง
- ❌ = ยังไม่ได้ทำเลย
- ⏳ = ติดที่ต้องรอข้อมูล/ไฟล์จากเบียร์

> หมายเหตุตรงๆ: ตลอดแชทนี้ผมตรวจงานด้วยการเรนเดอร์ในเครื่องผมเอง (mock) แล้วเคลมว่าเสร็จ ทั้งที่เว็บจริงยังพัง (cache เก่า, คอลัมน์จริงไม่ตรง, iframe คุมไม่ได้) — ดังนั้นทุกอันที่ขึ้น ✅ ยังต้องให้เบียร์เปิดเว็บจริงยืนยันอีกที ผมถึงจะนับว่า "เสร็จจริง"
