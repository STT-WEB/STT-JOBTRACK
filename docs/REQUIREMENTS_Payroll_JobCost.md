# A) JOB COST — ต้นทุนงานต่อจ๊อบ

## A1. เก็บเวลาจาก 2 ระบบ (คนละหน้าที่ ห้ามสับสน)

| ระบบ | หน้าที่ | ใช้ทำอะไร |
|---|---|---|
| **Bplus** | สแกนนิ้วเข้า-ออกงาน | ใช้**ทำจ่ายเงินเดือน** |
| **JOBTRACK** | พนักงาน 1 คนทำไปกี่จ๊อบ · แต่ละจ๊อบใช้เวลาเท่าไหร่ · ทำ **process** อะไร | ใช้**คิดต้นทุนลงจ๊อบ** |

## A2. Reconcile — 2 ตัว + ต้องหาต้นตอได้

| ด่าน | เทียบอะไร | ระดับ |
|---|---|---|
| A · **เช็คเวลา** | ชั่วโมง Bplus ↔ ชั่วโมง JOBTRACK | รายคน × รายวัน |
| B · **เช็คยอดเงิน** | ต้นทุนที่ลงจ๊อบ ↔ BP ที่จ่ายจริง | รายคน × งวด |
| C · เช็คกับบัญชี | ยอดจ่ายธนาคาร (HR) ↔ ยอดตัดธนาคาร (ACC) | ทั้งบริษัท × เดือน |

**ถ้าไม่ตรง ระบบต้องช่วย HR หาต้นตอ** — คลิกบรรทัดที่ต่าง → เปิดหน้าสืบสวน โชว์ตารางรายวันคู่กัน
(Bplus \| JOBTRACK \| ต่าง) ระบายเฉพาะวันที่ต่าง + ระบบเดาสาเหตุให้จาก 6 อาการ:

1. ลืม Check Out → ชั่วโมง JOBTRACK บวม
2. ลงจ๊อบซ้อนเวลา → คนเดียวอยู่ 2 จ๊อบช่วงเดียวกัน
3. ประเภทชั่วโมงผิด → ลง OT เป็นชั่วโมงปกติ ตัวคูณเลยผิด
4. ไม่ได้สแกนนิ้ว → มีใน JOBTRACK แต่ไม่มีใน Bplus
5. อัตราไม่ตรง Salary Master
6. ปฏิทินวันหยุดนักขัตฤกษ์ไม่ตรงกัน

+ ปุ่มบันทึกว่าแก้อะไร ใครแก้ เมื่อไหร่ (ย้อนดูได้)

## A3. คำนวณต้นทุน Direct รายบรรทัด

```
ชั่วโมงปกติ : ต้นทุน = (ยอดฐาน ÷ ชม.รวมที่ใช้หาร) × จำนวนชั่วโมง
ชั่วโมง OT  : ต้นทุน = OT Rate × Multiplier × จำนวนชั่วโมง

OT Rate  รายวัน   = อัตรา/วัน ÷ 8
         รายเดือน = เงินเดือน ÷ 30 ÷ 8
Multiplier มาจากตาราง Work Hour Type (1 / 1.5 / 3) และมีวันเริ่ม-สิ้นสุดผลบังคับ
```

- **กฎเหล็ก: ต้นทุน Direct รวมของเดือน = BP ที่ Payroll จ่ายจริง**
- ตาราง Cal **ตัดคอลัมน์สูตรคูณๆ ออก** เหลือแต่ผลลัพธ์ → ที่มาที่ไปย้ายไปเป็น popup ตอนคลิกตัวเลข

## A4. Allocate ค่าแรงทางอ้อม (Indirect) เข้าจ๊อบ — ทำหลัง Direct เสร็จ

**วิธีที่เบียร์เลือก: ตามชั่วโมงแรงงานตรง**

```
อัตราจัดสรร   = Indirect รวมของเดือน ÷ ชั่วโมง Direct รวมของเดือน
Indirect ของจ๊อบ = อัตราจัดสรร × ชั่วโมง Direct ของจ๊อบนั้น
ด่านตรวจ      : ผลรวม Indirect ทุกจ๊อบ = Indirect รวมของเดือน
```

> **หมายเหตุที่เบียร์ทัก — ค่าแรง Indirect ต่างจาก Direct เยอะ**
> ม.ค. 2569: Direct 672,889.55 (34.73%) · **Indirect 1,264,585.07 (65.27%)**
> แปลว่าอัตราจัดสรร 203.26 บาท/ชม. **สูงกว่าต้นทุน Direct เฉลี่ยเอง (~108 บาท/ชม.) เกือบ 2 เท่า**
> → ทุกจ๊อบจะแบก Indirect ประมาณ 2 เท่าของค่าแรงตรง
> **วิธีนี้ไม่สนว่าอัตรารายคนต่างกันแค่ไหน** เพราะเอา *ก้อนรวม* Indirect มาหาร ไม่ได้เอารายคนมาคิด
> จุดที่ต้องระวังจริง ๆ คือ จ๊อบที่จ้างผู้รับเหมาเยอะแต่ใช้คนบริษัทน้อย จะรับ Indirect น้อยผิดปกติ
> → ระบบจะมี **ธงเตือน** เมื่อจ๊อบไหนมีค่าแรงผู้รับเหมาสูงแต่ชั่วโมง Direct ต่ำ ให้เบียร์ตัดสินเป็นราย ๆ

## A5. เจาะดูราย Process

แต่ละจ๊อบ: ใช้กี่คน · แต่ละ process ใช้กี่ชั่วโมง · ต้นทุนแต่ละ process เท่าไหร่ · คิดเป็น %

## A6. เทียบงบ (หลังคิดต้นทุนเสร็จ)

| คอลัมน์ | มาจาก |
|---|---|
| Est. Budget | ตาราง `Budget labour` ในไฟล์ Payroll DB |
| Sale Budget | `SUM ของ billaftrDiscAmnt` |
| ค่าแรงผู้รับเหมา | `SUM ของ GoodAmnt` ต่อ JobCode |
| ส่วนต่าง Budget · % Cost/Budget · สถานะ | ระบบคำนวณ |
| เกณฑ์คุมค่าแรง ≤ 90% ของ Budget | จาก Master เดิม |

*(ค่าวัตถุดิบ = เฟสถัดไป ยังไม่รวมตอนนี้)*

## A7. Master รายจ๊อบ

- ค่าแรงรายเดือน **ม.ค. → ธ.ค. + ยอดยกมา** (จ๊อบข้ามปี ยอดต้องต่อเนื่อง)
- **START DATE → LATEST DATE DELIVERY → ใช้เวลากี่วันปิดจบงาน**
- TOTAL PROGRESS / สถานะส่งมอบ
- กรอง JT / JM / อื่น ๆ
- ตารางค่าแรงรายเดือน ต้องเห็นว่า **ค่าแรงเดือนนั้นไปลงจ๊อบไหนบ้าง** และ Direct ตรงกับ Payroll

## A8. Dashboard จ๊อบ

- ไทม์ไลน์ เริ่มงาน → ส่งมอบ (เขียว = ในช่วง · แดง = เลยกำหนด)
- สัดส่วนค่าแรงตามประเภทงาน รายเดือน
- หน้า Verify รายเดือน
- เจาะดูได้ทุกจ๊อบ

# B) PAYROLL — เงินเดือน

## B1. ข้อมูลการจ่ายเงินเดือนที่ถูกต้อง (ต้นทางความจริง)

งวดการจ่าย · อัตรา · เงินเดือน · OTx1 / x1.5 / x2 / x3 · Total OT
· สวัสดิการ (อาหาร, ตำแหน่ง/กว., โทรศัพท์-น้ำมัน, เบี้ยขยัน, ค่าเช่าบ้าน, Bonus, เงินได้พิเศษ)
· Benefit Fix / Non-Fix · **BP (ยอดจ่ายจริง)**

## B2. Dashboard ผู้บริหาร (ของใหม่ที่เบียร์สั่ง)

จากแท็บ **HR&ACC** ในไฟล์ตารางเงินเดือนจริง (HR เป็นคนกรอก · ระบบเอาไปวิเคราะห์ + ทำกราฟ):

- ยอดจ่าย/เดือน + **เทรนด์ 3 ปี (2567 / 2568 / 2569)**
- เปรียบเทียบ **เงินเดือน · สวัสดิการ · OT · เงินชดเชย** ว่าเพิ่ม-ลดกี่ %
- **จำนวนคนที่จ่ายเงินเดือนแต่ละเดือน** + เทรนด์
- **ยอดจ่ายธนาคาร (HR) เทียบ ยอดตัดธนาคาร (ACC)** → ธงแดงถ้าไม่ตรง
- สัดส่วน Direct / Indirect ทั้งจำนวนคนและจำนวนเงิน

## B3. สรุปค่าแรง (5 ข้อที่เคาะไว้เดิม — ยังอยู่ครบ)

1. เทียบเดือนต่อเดือน (▲▼ %)
2. ชี้เมาส์ที่กราฟ → ขึ้นยอดเต็ม ไม่ย่อ
3. แถบสีต่อแผนกใหญ่ + กางดูแผนกย่อย
4. Direct / Indirect (ยอด + %)
5. รายละเอียดรายพนักงานตามเดือน — **หน้า My Account ของพนักงานต้องตรงกับที่ HR เห็นเป๊ะ**

\+ **ค่าแรงปกติ เทียบ ค่า OT** และเจาะดูรายเดือน
\+ เทียบรายปี 2567–2569 (จากแท็บ HR&ACC — พนักงานไม่ต้องทำ Pivot ใหม่ทุกปี)
\+ มุมมองผู้บริหาร: แยกคน STT กับคนแผนก KEMREX ที่มาทำงานที่ STT

## B4. Performance พนักงาน Direct

```
ชม.มาตรฐานสุทธิ = ชม.มาตรฐาน − ชม.หยุดนักขัตฤกษ์
% Performance   = ชม.ปกติจาก Timesheet ÷ ชม.มาตรฐานสุทธิ
ต้นทุน/ชม.จริง   = (เงินเดือน + OT + สวัสดิการ) ÷ ชม.รวมทั้งหมด
```

| เกรด | %Performance |
|---|---|
| A+ | ≥ 95.00 |
| A | 90.00 – 94.99 |
| B | 85.00 – 89.99 |
| C | 80.00 – 84.99 |
| D | 75.00 – 79.99 |
| F | < 75.00 |

- **ชม.ขาด/ลา แยกเป็นธงเตือนต่างหาก** ไม่เอามาปนกับเกรด
- **เก็บสถิติรายปี** — ดูย้อนหลังได้ว่าคนนี้แต่ละเดือนทำได้เท่าไหร่

## B5. My Account (พนักงานดูของตัวเอง)

ชั่วโมง / ค่าแรง / OT รายเดือนและรายวันของตัวเอง — เลขชุดเดียวกับที่ HR เห็น

## B6. งานค้างที่ต้องแก้

**ลืม Check Out** → ตั้งธงแดงให้ HR + เตือนพนักงานทาง LINE + ล็อกไม่ให้เอาชั่วโมงนั้นเข้าต้นทุนจนหัวหน้ายืนยัน
