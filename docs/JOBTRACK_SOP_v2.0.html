3.4 กรณีพิเศษ Special Cases
กรณีวิธีแก้ไข
ลืม Check Out งานเมื่อวานแจ้ง Admin ทันที ให้ Admin แก้ใน Job_Log โดยใส่เวลา Check Out และชั่วโมงด้วยตนเอง
Check In ผิด Jobแจ้ง Admin ทันที อย่า Check Out เอง เพราะจะบันทึกข้อมูลผิด
เปลี่ยนมือถือหรือมือถือหายแจ้ง Admin → Admin ลบ LINE ID เดิมออกจาก Employee_List → ลงทะเบียนใหม่ผ่าน QR Register
มือถือแบตหมดตอน Check Outชาร์จแบตแล้ว Check Out ทันที หรือแจ้ง Admin ถ้านานกว่า 30 นาที
เน็ตไม่มีตอน Check In/Outรอจนมีเน็ต แล้ว Check In/Out ตามเวลาจริง เพราะระบบบันทึกเวลาปัจจุบัน
