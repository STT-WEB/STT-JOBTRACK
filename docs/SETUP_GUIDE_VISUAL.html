01
สร้าง Google Sheet
Google Sheet จะเป็น Database เก็บข้อมูลพนักงานทุก Check In/Out
1
เปิด Google Sheets
ต้อง Login Google Account ของบริษัทหรือตัวเองก่อน
1
เปิด Browser แล้วพิมพ์ใน Address Bar
sheets.google.com
2
กด Enter → หน้า Google Sheets จะเปิดขึ้น
2
สร้าง Spreadsheet ใหม่
1
กดปุ่ม "+ Blank" หรือ "สร้าง" ที่มุมซ้ายบน
2
Spreadsheet ว่างเปล่าจะเปิดขึ้น → คลิกชื่อ "Untitled spreadsheet" ที่มุมซ้ายบนสุด แล้วแก้เป็น JOBTRACK_Database
3
กด Enter เพื่อยืนยันชื่อ
3
Copy Sheet ID จาก URL
นี่คือ "รหัส" ที่ Apps Script จะใช้หา Sheet
1
มองที่ Address Bar ของ Browser จะเห็น URL แบบนี้
docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit#gid=0
// URL แบ่งเป็น 3 ส่วน:
docs.google.com/spreadsheets/d/ ← prefix ปกติ
1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms ← Sheet ID (ต้องการส่วนนี้)
/edit#gid=0 ← suffix ปกติ
2
ลาก เลือก (Highlight) เฉพาะส่วนตรงกลาง — ตัวอักษรยาวๆ ระหว่าง /d/ กับ /edit
3
กด Ctrl+C (Windows) หรือ Cmd+C (Mac) เพื่อ Copy
4
เปิด Notepad หรือ Notes แล้ว Paste ไว้ก่อน จะได้ใช้ในขั้นตอนถัดไป
⚠️
อย่าปิด Tab นี้ เดี๋ยวต้องกลับมาเปิด Apps Script จาก Sheet นี้ต่อ
02
ตั้งค่า Google Apps Script
Apps Script คือ "Backend" ที่รับข้อมูลจาก Web App แล้วเขียนลง Sheet
1
เปิด Apps Script จาก Sheet
1
กลับไปที่ Tab JOBTRACK_Database ที่เปิดค้างไว้
2
คลิก Menu bar ด้านบน → กด "Extensions" (หรือ "ส่วนเสริม" ถ้าเป็นภาษาไทย)
FileEditViewInsertFormatDataToolsExtensions ←Help
📝 Apps Script
🔌 Add-ons
⚡ Macros
3
คลิก "Apps Script" → Tab ใหม่จะเปิดขึ้น มีหน้า Editor สีขาว
2
วางโค้ดลงใน Editor
1
ใน Apps Script Editor จะมีโค้ดเริ่มต้นอยู่แล้วแบบนี้
// เห็นโค้ดแบบนี้อยู่ → ลบทิ้งทั้งหมด
function myFunction() {
  // ...
}
2
คลิกใน Editor → กด Ctrl+A (เลือกทั้งหมด) → กด Delete ลบออกให้หมด
3
เปิดไฟล์ jobtrack_apps_script.gs ที่ Candy ส่งให้ → Copy โค้ดทั้งหมด (Ctrl+A แล้ว Ctrl+C)
4
กลับมาที่ Apps Script Editor → Paste ลงไป (Ctrl+V)
3
ใส่ Sheet ID ที่ Copy ไว้
1
ใน Editor หาบรรทัดที่เขียนว่า
// บรรทัดที่ต้องหาและแก้
const SHEET_ID = 'SHEET_ID_HERE';
2
ลบ SHEET_ID_HERE แล้ว Paste Sheet ID ที่ Copy มาจากขั้นตอนที่ 1 แทน
// หลังแก้แล้ว จะได้แบบนี้ (Sheet ID ของเบียร์จะต่างออกไป)
const SHEET_ID = '1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms';
3
กด Ctrl+S เพื่อ Save
4
ทดสอบ + ให้สิทธิ์ครั้งแรก
1
ที่ Dropdown ข้าง ▶ Run → คลิก เปลี่ยนจาก myFunction เป็น testInsert
function: testInsert ▼
▶ Run
2
กดปุ่ม ▶ Run → จะมี Popup ขอสิทธิ์ขึ้นมา
🔐
Popup "Authorization required": กด "Review permissions" → เลือก Google Account ของเบียร์ → กด "Advanced" → "Go to JOBTRACK (unsafe)" → "Allow" — นี่คือ Script ของเบียร์เอง ปลอดภัยแน่นอน
3
หลัง Allow แล้ว Script จะรันอีกครั้งอัตโนมัติ → กลับไปดู JOBTRACK_Database Sheet จะมี Tab ใหม่ชื่อ Job_Log และมีข้อมูล 1 แถว = สำเร็จ! ✅
03
Deploy และเชื่อม Web App
Deploy = เปิดให้ Apps Script รับข้อมูลจาก Web App ได้จริง
1
Deploy เป็น Web App
1
ใน Apps Script Editor กดปุ่ม "Deploy" (มุมบนขวา) → เลือก "New deployment"
Deploy ▼
🚀 New deployment
📋 Manage deployments
2
กด icon ⚙️ ข้าง "Select type" → เลือก "Web app"
3
ตั้งค่าดังนี้ (สำคัญมาก!)
Fieldค่าที่ต้องใส่
DescriptionJOBTRACK v1
Execute asMe (ชื่อ Google Account ของเบียร์)
Who has accessAnyone  ← สำคัญมากที่สุด!
⚠️
"Who has access" ต้องเป็น "Anyone" เท่านั้น ถ้าเป็น "Only myself" Web App มือถือพนักงานจะส่งข้อมูลไม่ได้
4
กดปุ่ม "Deploy" → รอสักครู่
2
Copy Web App URL
1
หลัง Deploy สำเร็จ จะมี Popup แสดง Web app URL
// URL ที่จะได้หน้าตาแบบนี้
https://script.google.com/macros/s/AKfycbxXXXXXXXXXXXXXXXXX/exec
2
กดปุ่ม "Copy" ข้าง URL นั้น → Paste ไว้ใน Notepad ก่อน
3
กด "Done" ปิด Popup
3
ใส่ URL ใน Web App (job_checkin_app.html)
1
เปิดไฟล์ job_checkin_app.html ด้วย Notepad หรือ Text Editor (คลิกขวา → Open with → Notepad)
2
กด Ctrl+F ค้นหาคำว่า YOUR_APPS_SCRIPT_URL_HERE
// หาบรรทัดนี้ใน job_checkin_app.html
const APPS_SCRIPT_URL = 'YOUR_APPS_SCRIPT_URL_HERE';
3
ลบ YOUR_APPS_SCRIPT_URL_HERE แล้วใส่ Web App URL ที่ Copy มาแทน
// หลังแก้แล้ว จะได้แบบนี้
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/AKfycb.../exec';
4
กด Ctrl+S Save ไฟล์
