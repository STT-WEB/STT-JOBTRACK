## 3. Payroll · Job Cost — โฟกัสหลัก

### 3.1 สรุปค่าแรง (เอาแบบง่าย 5 ข้อ ตามที่เบียร์เคาะ)
ข้อมูลต้อง **ตรงกับ Pivot ที่เบียร์ทำ** ดึงจาก DATA BASE ดิบ (ปีนี้) โชว์เฉพาะที่อยากได้ (ไม่ยกทั้ง Pivot มา):
1. เทียบได้ **เดือนต่อเดือน** (เพิ่ม/ลด ▲▼ %)
2. ชี้เมาส์ที่กราฟ → ขึ้น **ยอดเต็ม** (ไม่ย่อ ฿K)
3. **แถบสีต่อแผนกใหญ่** → บอกยอดแต่ละแผนก
4. ยอด **Direct / Indirect** (ยอด + %)
5. **รายละเอียดรายพนักงาน ตามเดือน** — และหน้า **my acc + hr** ต้องตรงกัน

**กติกาตัวเลข:** ทุกช่อง 2 ทศนิยม + ลูกน้ำ · ชั่วโมง = เลขปกติ (ไม่มีลูกน้ำ)

**แผนกใหญ่ (ตามรหัสแผนก):** 1=HR · 2=Account · 3=Design · 4=After Sale Service · 5=Production · 6=Purchase · 7=QC · 8=Sale · 9=Safety · 11=Estimate · 12=Dcc & Admin (กางดูแผนกย่อยได้ + แยกสี)

- **เทียบรายปี** 2567–ปัจจุบัน: อ่านจากแท็บ **HR&ACC** (HR กรอกยอด account รายเดือน) — ปีเก่าเป็น copy วาง, ตั้งแต่ 69 อยู่คนละไฟล์ต่อปี, **ห้ามให้พนักงานทำ Pivot ใหม่ทุกปี**
- **CEO** = รวม STT + KEMREX

### 3.2 แท็บอื่นใน Payroll·JobCost
| แท็บ | หมายเหตุ |
|------|---------|
| Time Bplus | ไฟล์รายเดือนชื่อ "N.Time Bplus …" เป็น **Excel** → ต้องแปลงเป็น Google Sheets ก่อนระบบถึงอ่านได้ |
| Time JOBTRACK | ชั่วโมงรายวัน + กรอง + หัวตรึง |
| Reconcile | เดือน 1–7 ยังเทียบไม่ได้ (บอกชัด) |
| Data Payroll | อ่าน Payroll Actual กรองเดือน |
| Cal Jobcost | คำนวณรายบรรทัด |

### 3.3 Job Cost — เทียบต้นทุน (❓ ยังขาดแหล่งข้อมูล)
อยากเทียบต้นทุนจริง กับ **Estimate (งบตั้งต้น)** และ **Budget Sale** (+ ค่าวัตถุดิบ)
**❓ ต้องเคาะ:** Estimate / Budget Sale อยู่ไฟล์ไหน คอลัมน์อะไร ผูกกับจ๊อบยังไง

## 7. ลำดับที่จะเดินในแชทใหม่
1. เคาะ **ภาพรวม + โครงเมนู** (ข้อ 1) → Mockup โครง Hub
2. เคาะ **หน้า Login/Welcome** (ข้อ 2) → Mockup
