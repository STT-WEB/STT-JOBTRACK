1. วัตถุประสงค์ Purpose

เอกสารฉบับนี้อธิบายขั้นตอนการใช้งานระบบ JOBTRACK สำหรับบันทึกเวลาการทำงานของพนักงาน โดยแบ่งตามบทบาทหน้าที่ของผู้ใช้งานแต่ละกลุ่ม

2. ขอบเขตการใช้งาน Scope
เบียร์ (Owner) Admin พนักงาน หัวหน้าหน่วยงาน
ตั้งค่าและดูแลระบบทั้งหมด จัดการ Job และพนักงาน Check In/Out งานประจำวัน ตรวจสอบ Process และรายงาน
3. สิ่งที่ต้องมีก่อนเริ่มใช้งาน Prerequisites
#สิ่งที่ต้องมีรายละเอียด
1มือถือส่วนตัวAndroid หรือ iOS ที่มี LINE App ติดตั้งอยู่แล้ว
2LINE Accountบัญชี LINE ส่วนตัว ไม่ต้องมี Email ก็ได้
3BrowserChrome (Android) หรือ Safari (iOS) — ห้ามใช้ LINE Browser
4อินเตอร์เน็ตWiFi หรือ Data มือถือ
5รหัสพนักงานรับจาก HR ตอนลงทะเบียนครั้งแรก

PART 1 — เบียร์ (System Owner)

ตั้งค่าระบบครั้งแรก · ดูแล Infrastructure · แก้ไขปัญหาระดับ System

เบียร์
System Owner
ตั้งค่าและดูแลระบบทั้งหมด มีสิทธิ์สูงสุด แก้ไขโค้ดและ Deploy ได้
3.1 การตั้งค่าครั้งแรก One-time Setup
1
เปิด Google Sheet JOBTRACK_Database
Open Google Sheet
💡 ต้อง Login ด้วย Google Account ของบริษัท
2
Extensions → Apps Script → วางโค้ดจากไฟล์ jobtrack_apps_script.gs
Paste Apps Script code
3
แก้ SHEET_ID ในโค้ดให้ตรงกับ Sheet ของบริษัท
Update Sheet ID
💡 Copy จาก URL ของ Google Sheet
4
ตั้งค่า appsscript.json เพิ่ม oauthScopes 3 รายการ
Configure OAuth Scopes
5
Deploy เป็น Web App → Execute as: Me → Anyone → Copy URL
Deploy as Web App
6
อัปเดต URL ใน job_checkin_app.html บรรทัด APPS_SCRIPT_URL
Update Apps Script URL in Web App
7
Upload ไฟล์ทั้งหมดขึ้น GitHub Repository
Upload files to GitHub
8
GitHub → Settings → Pages → Main Branch → Save
Enable GitHub Pages
9
ทดสอบเปิด URL: stt-web.github.io/STT-JOBTRACK/job_checkin_app.html
Test Web App URL
⚠️ URL ที่ได้จาก GitHub Pages ใช้ได้ตลอดไป ไม่ต้องแก้อีก
3.2 การดูแลระบบประจำเดือน Monthly Maintenance
1
เปิด Tab Job_List → เพิ่ม Job ใหม่ประจำเดือน (คอลัมน์ A B C)
💡 QR Link จะ Generate อัตโนมัติใน Column E
2
เปิด qr_generator.html → Copy คอลัมน์ E → Generate QR → Print
3
Job ที่เสร็จแล้ว → เปลี่ยนสถานะเป็น Done ใน Job_List
4
ตรวจสอบ Apps Script Quota: script.google.com → Executions
3.3 Troubleshooting Guide
ปัญหาสาเหตุวิธีแก้ไข
Check In ไม่ได้ หมุนค้างยังไม่ได้ Deploy New versionDeploy → Manage deployments → New version
Error 403Who has access ไม่ได้ตั้งเป็น AnyoneDeploy ใหม่ → ตั้ง Who has access: Anyone
QR Link ไม่ขึ้นTrigger ยังไม่ได้ติดตั้งApps Script → testInstallTrigger → Run
พนักงานลงทะเบียนไม่ได้Employee_List ยังไม่ได้ ImportApps Script → testImportEmployee → Run
รูปภาพ Upload ไม่สำเร็จเปิดจาก LINE Browserแจ้งพนักงานให้เปิดใน Chrome โดยตรง

PART 2 — Admin (ผู้ดูแลระบบ)

จัดการ Job ประจำเดือน · ลงทะเบียนพนักงานใหม่ · ออก QR Code

Admin
ผู้ดูแลระบบ
จัดการ Job_List, Employee_List, ออก QR Code และดูแลพนักงานในระบบ
4.1 การเพิ่ม Job ใหม่ Adding New Jobs
1
เปิด Google Sheet JOBTRACK_Database → Tab Job_List
2
เลื่อนลงแถวว่างสุดท้าย → กรอกข้อมูล 3 ช่อง
💡 A = ประเภทงาน (JM/JT/JMS/JP/Other Job) | B = Job Code | C = ชื่อลูกค้า
3
QR Link จะขึ้นในคอลัมน์ E อัตโนมัติทันที
QR Link auto-generates in Column E
4
เปิดไฟล์ qr_generator.html ใน Browser
5
กลับไป Job_List → Copy คอลัมน์ E ทั้งหมด → Paste ใน QR Generator
6
กด Generate QR → ตรวจสอบว่าขึ้นครบทุก Job
7
กด 🖨️ พิมพ์ → ตัดแล้วติดที่แท็งค์/หน้างาน
⚠️ Job Code ต้องไม่ซ้ำกัน เช่น JM-69/0001, JT-69/0050
4.2 การลงทะเบียนพนักงานใหม่ New Employee Registration
1
ตรวจสอบว่าพนักงานใหม่มีชื่ออยู่ใน Tab DATA EMPLOYEE แล้ว
2
ถ้ายังไม่มี → เพิ่มข้อมูลใน DATA EMPLOYEE ก่อน
3
Apps Script → เลือก testImportEmployee → ▶ Run เพื่อ Sync ข้อมูลใหม่
💡 LINE ID เดิมของพนักงานคนอื่นจะไม่หาย
4
พิมพ์ QR Register แจกให้พนักงานใหม่
💡 URL: stt-web.github.io/STT-JOBTRACK/register.html — QR ใบเดียวใช้ได้กับทุกคน
5
ให้พนักงานสแกน QR → Login LINE → กรอกรหัสพนักงาน
6
ตรวจสอบ Tab Employee_List ว่า LINE ID ขึ้นถูกต้อง
4.3 การจัดการ Job เสร็จสิ้น Closing Completed Jobs
1
เปิด Tab Job_List → หา Job ที่เสร็จแล้ว
2
เปลี่ยนคอลัมน์ D (สถานะ) จาก Active เป็น Done
3
ถอด QR Code ที่ติดอยู่หน้างานออก

PART 3 — พนักงาน (Employee)

ลงทะเบียนครั้งแรก · Check In/Out ทุกครั้งที่เริ่ม/เสร็จงาน · ถ่ายรูป Evidence

พนักงาน
Employee
สแกน QR ที่หน้างาน → Check In/Out → ถ่ายรูป ทำซ้ำทุกครั้งที่มีงานใหม่
⚠️ ลงทะเบียนครั้งแรกหนึ่งครั้ง → ระบบจำตลอดไป ไม่ต้องทำซ้ำ
5.1 การลงทะเบียนครั้งแรก First-time Registration — ทำครั้งเดียว
1
รับ QR Register จาก HR หรือ Admin
2
เปิดกล้องมือถือ (ห้ามเปิดจาก LINE) → สแกน QR
Open phone camera — NOT LINE — then scan QR
💡 ถ้าเปิดจาก LINE → กด 3 จุด มุมขวาบน → เปิดใน Chrome
3
กด "เข้าสู่ระบบด้วย LINE" → เลือก Account ของตัวเอง
4
กรอกรหัสพนักงาน (ตัวเลข) ด้วย Numpad บนหน้าจอ
💡 รหัสพนักงานดูได้จากสลิปเงินเดือน หรือถาม HR/Admin
5
กด ยืนยัน → ตรวจสอบชื่อและแผนกที่ขึ้นมา
6
หน้า "ลงทะเบียนสำเร็จ" ขึ้น = เสร็จสมบูรณ์ ✅
7
เพิ่ม Shortcut บน Home Screen: กด ⋮ → เพิ่มในหน้าจอหลัก
💡 ครั้งต่อไปกดจาก Home Screen ได้เลย ไม่ต้องผ่าน LINE
5.2 การ Check In เข้างาน Check In
1
เดินไปที่แท็งค์/หน้างาน → เปิดกล้องมือถือ → สแกน QR ของงานนั้น
2
หน้า App เปิดขึ้น → ตรวจสอบชื่อและ Job ID ที่แสดง
3
กด ▶ เข้างาน (ปุ่มสีเขียว)
4
เลือก Process ที่กำลังทำ (แตะที่ Icon)
💡 Fabrication / Reinstall / Piping / System / วัดน้ำ / Sticker / ทำสี / QC
5
กด บันทึก → รอหน้าสำเร็จขึ้น → เห็นเวลาเข้างาน ✅
🚫 ถ้าระบบแจ้งว่ามีงานค้างอยู่ ต้องไป Check Out งานเดิมก่อน
5.3 การ Check Out ออกงาน Check Out
1
สแกน QR ของงานนั้น → หน้า App เปิดขึ้น
2
กด ■ ออกงาน (ปุ่มสีแดง)
3
Section ถ่ายรูปปรากฏขึ้น → กด ถ่ายรูป
💡 บังคับถ่ายอย่างน้อย 1 รูป สูงสุด 3 รูป
4
ถ่ายรูปงานให้เห็นชัดเจน → กด ตกลง
5
ตรวจสอบรูปที่ถ่าย → กด บันทึก
6
หน้า "ออกงานสำเร็จ" ขึ้นพร้อมชั่วโมงรวม
7
รอดู → ขึ้น ✅ Upload สำเร็จ = เสร็จสมบูรณ์
🚫 รูปต้องถ่ายจากกล้องสดเท่านั้น ห้ามใช้รูปจาก Gallery ระบบจะปฏิเสธอัตโนมัติ
5.4 เมื่อเกิดปัญหา Troubleshooting for Employees
ปัญหาที่พบวิธีแก้ไข
เปิดจาก LINE แล้วกล้องไม่ทำงานกด 3 จุด → เปิดใน Chrome แล้วสแกน QR ใหม่
ระบบแจ้งว่ามีงานค้างอยู่ไปที่แท็งค์งานเดิม → สแกน QR → Check Out ก่อน
รหัสพนักงานไม่ถูกต้องติดต่อ HR หรือ Admin เพื่อตรวจสอบรหัส
Upload รูปไม่สำเร็จเช็ค Internet → ลอง Check Out ใหม่ หรือแจ้ง Admin
หน้าจอหมุนนานมากRefresh หน้า → ลองใหม่ หรือแจ้ง Admin

PART 4 — หัวหน้าหน่วยงาน (Supervisor)

ตรวจสอบการทำงาน · ดู Process · ชั่วโมงการทำงาน · รูปภาพ Evidence

หัวหน้า
Supervisor
เปิด Google Sheet → ดูข้อมูลการทำงาน ชั่วโมง Process และรูปภาพ Evidence ของพนักงาน
6.1 การดูข้อมูลการทำงาน Viewing Work Data
1
เปิด Google Sheet JOBTRACK_Database
2
คลิก Tab Job_Log ด้านล่าง
3
ตรวจสอบข้อมูลจากคอลัมน์ต่างๆ ตามตารางด้านล่าง
Colหัวข้อข้อมูลที่เห็น
Bวันที่วันที่ทำงาน
Cเวลาเข้าเวลาที่พนักงาน Check In
Dเวลาออกเวลาที่พนักงาน Check Out
Eชม.รวมจำนวนชั่วโมงที่ทำงาน
FJob IDรหัสงานที่ทำ
Jชื่อพนักงานชื่อ-นามสกุลพนักงาน
LสถานะCheck In / Check Out
MProcessประเภทงานที่ทำ
Oหมายเหตุ📷 Link รูปภาพ Evidence (คลิกได้เลย)
Pประเภทวันทำงานวันทำงานปกติ / วันหยุด / วันหยุดนักขัตฤกษ์
Qประเภทชั่วโมงชม.ปกติ / OT x1.5 / วันหยุด / OT วันหยุด x3
6.2 การดูรูปภาพ Evidence Viewing Photo Evidence
1
เปิด Tab Job_Log → หาแถว Check Out ของพนักงานที่ต้องการ
2
ดูคอลัมน์ O (หมายเหตุ) จะเห็น 📷 รูปที่ 1, 📷 รูปที่ 2
3
คลิกที่ 📷 รูปที่ 1 → Browser จะเปิดรูปขึ้นมาทันที
4
ตรวจสอบรูปว่างานเสร็จถูกต้องหรือไม่
💡 รูปทุกรูปจะมี Watermark แสดงชื่อพนักงาน รหัส Job และเวลาถ่ายอัตโนมัติ
6.3 การกรอง Filter ข้อมูล Filtering Data
1
ใน Job_Log → กด ไอคอน Filter ที่แถว Header
2
กรอง "ชื่อพนักงาน" — เพื่อดูเฉพาะคนที่ต้องการ
3
กรอง "Job ID" — เพื่อดูงานเฉพาะ Job
4
กรอง "Process" — เพื่อดูประเภทงานที่ต้องการ
5
กรอง "วันที่" — เพื่อดูช่วงเวลาที่ต้องการ
6.4 เมื่อพบปัญหา — แจ้ง Admin ทันที Escalation to Admin
กรณีที่พบให้แจ้ง Admin ทันที
พนักงาน Check In แต่ไม่มีข้อมูลใน Sheetแจ้ง Admin ตรวจสอบ Apps Script
รูปภาพไม่ขึ้นในคอลัมน์หมายเหตุแจ้ง Admin ตรวจสอบ ImgBB API Key
ชั่วโมงรวมผิดปกติ (0 หรือลบ)แจ้ง Admin ตรวจสอบการคำนวณ
ประเภทวันทำงานผิดแจ้ง Admin อัปเดต Tab ประเภทวันทำงาน
