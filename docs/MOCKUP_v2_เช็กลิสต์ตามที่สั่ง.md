## A) JOB COST — ทำแล้วอยู่ตรงไหน

| ข้อที่สั่ง | อยู่แท็บ | ทำอะไรให้ |
|---|---|---|
| Bplus = สแกนนิ้ว ใช้จ่ายเงินเดือน | Job Cost ① | สถานะไฟล์รายเดือน (เดือนล่าสุดยังไม่แปลง → บอกตรง ๆ ว่าอ่านไม่ได้) + ปุ่มแปลง/นำเข้า |
| JOBTRACK = 1 คนทำกี่จ๊อบ กี่ชั่วโมง process อะไร | Job Cost ② | ตาราง "พนักงาน 1 คน ทำไปกี่จ๊อบ" + **คลิกแถวเพื่อเจาะดูว่าลงจ๊อบไหน process อะไร กี่ชั่วโมง กี่ %** |
| **Reconcile 2 ตัว** | Job Cost ③ | ① เช็คเวลา (Bplus↔JOBTRACK) และ ② เช็คยอดเงิน (ต้นทุนลงจ๊อบ↔BP) อยู่ในตารางเดียวกัน แยกคอลัมน์ชัด |
| ไม่ตรงต้องหาต้นตอ | Job Cost ③ | **คลิกแถวที่ไม่ตรง → เปิดหน้า "หาต้นตอ"** : เทียบรายวัน Bplus vs JOBTRACK ระบายเฉพาะวันที่ต่าง + ระบบเดาสาเหตุให้ + ช่องบันทึกว่าแก้อะไร |
| คิดต้นทุน Direct รายบรรทัด | Job Cost ④ | **ตัดคอลัมน์สูตรคูณๆ ออกหมด** เหลือแต่ผลลัพธ์ · กติกาอธิบายไว้ในกล่องด้านบน |
| กฎเหล็ก Direct = Payroll จ่ายจริง | Job Cost ④ + ⑦ | KPI เทียบให้เห็นทันที + ตารางด่านตรวจรายเดือนครบ 8 เดือน (ตรงกันทุกเดือน) |
| **Allocate Indirect เข้าจ๊อบ** | Job Cost ⑤ | อัตราจัดสรร = Indirect รวม ÷ ชั่วโมง Direct รวม · ตารางรายจ๊อบ + กราฟ + ด่านตรวจว่ารวมกลับได้เท่าก้อนเดิม + **ธงเตือนจ๊อบที่จ้างผู้รับเหมาสูง** |
| เทียบ Est. Budget / Sale Budget | Job Cost ⑥ | ยอดยกมา · ค่าแรง STT · Indirect ที่ปัน · ค่าแรงผู้รับเหมา · ต้นทุนรวม · Est. Budget · ส่วนต่าง · **% Cost/Budget (เกิน 90% เตือน)** · Sale Budget |
| Master: ค่าแรง ม.ค.–ธ.ค. + ยอดยกมา | Job Cost ⑦ | ตารางเต็ม 12 เดือน + ยอดยกมาข้ามปี (เลื่อนขวาดูได้) |
| **เริ่มงาน → ปิดจบ ใช้กี่วัน** | Job Cost ⑦ | คอลัมน์ "ใช้เวลา (วัน)" + KPI ระยะเวลาปิดจบเฉลี่ย/เร็วสุด/ช้าสุด |
| เจาะราย Process | Job Cost ⑧ | ตาราง process: ใช้กี่คน กี่ชั่วโมง ต้นทุนเท่าไหร่ **กี่ %** + กราฟสัดส่วนรายเดือน |
| ไทม์ไลน์ + สถานะส่งมอบ | Job Cost ⑧ | เขียว=ส่งมอบแล้ว · แดง=เลยกำหนด · น้ำเงิน=อยู่ในช่วง + เส้นวันส่งมอบ |

## B) PAYROLL — ทำแล้วอยู่ตรงไหน

| ข้อที่สั่ง | อยู่แท็บ | ทำอะไรให้ |
|---|---|---|
| เงินเดือนที่จ่ายจริง | Payroll ① | ค่าแรง+สวัสดิการ · OT1.5 · OT3 · ทำงานวันหยุด · OT รวม · BP · ประกันสังคม · สุทธิ + ด่านตรวจ |
| **Dashboard ผู้บริหาร (ของใหม่)** | Payroll ② | ยอด/เดือน + เทรนด์ 3 ปี · **จำนวนคนที่จ่ายแต่ละเดือน** · โครงสร้าง เงินเดือน/สวัสดิการ/OT/เงินชดเชย · %เพิ่ม-ลดทุกตัว |
| **ตรงกับที่บัญชีจ่ายออกไหม** | Payroll ② | คอลัมน์ **จ่ายธนาคาร (HR) เทียบ ตัดธนาคาร (ACC)** + ธงแดงเดือนที่ไม่ตรง + KPI นับเดือนที่ต้องตรวจ |
| สรุปค่าแรง 5 ข้อเดิม | Payroll ③ | ครบเหมือนเดิม (เดือนต่อเดือน ▲▼% · tooltip ยอดเต็ม · แถบสีแผนก · Direct/Indirect · รายพนักงาน) |
| ค่าแรง เทียบ OT + เจาะรายเดือน | Payroll ③ หน้าย่อย 2 | กราฟ + ตาราง + เจาะรายแผนกในเดือนที่เลือก |
| เทียบรายปี 2567–2569 | Payroll ③ หน้าย่อย 3 | ดึงจากแท็บ HR&ACC |
| แยกคน STT / คน KEMREX | Payroll ③ หน้าย่อย 4 | + ปุ่มสลับ "นับรวม / ไม่นับ" ที่หัวโมดูล |
| **Performance พนักงาน Direct** | Payroll ④ | %Performance = ชม.ปกติ ÷ ชม.มาตรฐานสุทธิ · **เกรด A+≥95 / A 90–94.99 / B 85–89.99 / C 80–84.99 / D 75–79.99 / F <75** · **ขาด/ลาแยกเป็นธง ไม่ปนกับเกรด** · **สถิติรายปี** (กราฟ %เฉลี่ยรายเดือน) |
| My Account | โมดูล My Acc | ชั่วโมง/ค่าแรงของตัวเอง + **จ๊อบที่ทำเดือนนั้น** + Performance ของตัวเอง |

## การตรวจสอบที่ทำก่อนส่ง

| ตรวจอะไร | ผล |
|---|---|
| ค่าแรง Direct ที่ลงจ๊อบ = BP ที่ Payroll จ่ายจริง | ✅ ตรงทุกเดือน ทั้ง 2 บริษัท |
| ชั่วโมงพนักงาน Direct = ชั่วโมงที่ลงจ๊อบ | ✅ ตรงทุกเดือน |
| Indirect ที่กระจายเข้าทุกจ๊อบ = ก้อน Indirect ของเดือน | ✅ ตรงทุกเดือน |
| ยอดยกมา + ค่าแรง STT + Indirect + ผู้รับเหมา = Total Cost | ✅ ตรงทุกจ๊อบ |
| ค่าแรงปกติ + OT = ยอดจ่ายจริง · Direct + Indirect = ยอดรวม | ✅ ตรงทุกเดือน |
| ผลรวมต่อ Process = ผลรวมค่าแรงทุกจ๊อบ | ✅ ตรง |
| HR&ACC: เงินสด + ธนาคาร = ยอดจ่ายสุทธิ | ✅ ตรงทุกเดือน (จงใจใส่ 2 เดือนที่ HR≠ACC ให้เห็นธงแดง) |
| **ตัวตรวจกราฟล้นกรอบอัตโนมัติ** — ไล่ทุกกราฟ ทุกแท็บ ทุกเดือน ทั้ง 2 บริษัท | ✅ ไม่มีอะไรวาดออกนอกกรอบ |
| ตัวตรวจคณิตศาสตร์ที่รันบนหน้าเว็บจริง | ✅ ผ่านทุกข้อ |
| JavaScript syntax + console error | ✅ ไม่มี error |
| เรนเดอร์จริงด้วย Chromium แคปดูครบทุกหน้า (22 หน้า) | ✅ ตรวจแล้ว |

## ยังค้าง / รอเบียร์

1. **รหัสแผนก KEMREX** — ผมใช้ **10** (เลข 10 ว่างอยู่ในรหัสที่เบียร์ให้) รอยืนยัน
2. **Estimate ของจริง** — ตอนนี้ Est. Budget เป็นตัวเลขสมมติ · ของจริงเอามาจาก `Budget labour` ในไฟล์ Payroll DB ได้เลย รอเบียร์ยืนยันว่าใช่ตัวนั้น
3. **ค่าวัตถุดิบ** — ยังไม่รวมตามที่ตกลง (เฟสถัดไป)
4. **เกณฑ์เตือน %OT** — ผมตั้ง เหลือง >12% แดง >18% ปรับได้
5. **ล็อกโครงคอลัมน์ JOBTRACK** — ของจริงเปลี่ยนคอลัมน์มา 4 รอบในปีเดียว ระบบจะมี Column Map รองรับ แต่ควรหยุดเปลี่ยนได้แล้ว
