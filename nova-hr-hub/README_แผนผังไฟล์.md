## ปุ่มเดียวจบ

```
ดับเบิลคลิก  อัปเดต-Hub.bat
   1) เก็บโค้ดขึ้น GitHub
   2) clasp push -f       ← ส่งไฟล์ทั้งหมดขึ้น Apps Script
   3) clasp deploy        ← ออกเวอร์ชันใหม่บน URL เดิม (ลิงก์ไม่เปลี่ยน)
```

จากนั้นเปิดเว็บแล้วกด **Ctrl + Shift + R**

**ครั้งแรกให้ทำก่อน 1 ครั้ง:** เปิด Apps Script Editor → เลือกฟังก์ชัน **`probe()`** → กด Run
มันจะพิมพ์ชื่อแท็บทั้งหมดในไฟล์จริง บอกว่าแท็บไหนหาไม่เจอ และรันด่านตรวจ 8 ข้อให้ดู

## เช็กว่า deploy ขึ้นจริงไหม

มุมขวาบนของหน้าแอปมีป้าย `NOVA-HR v3.0 · ปีงบ 2569`
และใน `WebApp.gs` มี `HUB_VERSION` — บวกเลขทุกครั้งที่แก้โค้ด ถ้าเลขบนเว็บยังเป็นของเก่า = ยังไม่ขึ้น

ถ้าตัวเลขไม่อัปเดตแต่โค้ดขึ้นแล้ว → รัน **`forceRefresh()`** ใน Apps Script (ล้างแคช 5 นาที)
